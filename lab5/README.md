# Лабораторная 5. Предобработка данных для ML и основы аналитики

**Иноземцев Сергей Викторович · ЕТ-216**

[lab5.ipynb](lab5.ipynb) выполняет все части 1–6 вложения к [заданию №5](https://edu.susu.ru/mod/assign/view.php?id=8817998): SMART и MECE, смещения выборки, типы признаков, сравнение скейлеров, кодирование категорий, ColumnTransformer и выборки. В конце добавлено сравнение удаления и заполнения пропусков, поскольку на странице курса работа названа «Предобработка пропусков».

| Таблица | Содержание |
|---|---|
| bank_customers.csv | 800 синтетических клиентов, исходные 7 признаков и Churn; seed=42 |
| prepared_train.csv | 600 строк и 11 подготовленных признаков; source_row связывает их с исходными строками |
| prepared_test.csv | 200 строк и 11 подготовленных признаков; source_row — технический индекс, не вход модели |
| imputation_comparison.csv | Покрытие, ROC AUC и ошибка восстановления искусственно скрытого дохода |

Запускать ячейки сверху вниз в новом Python-ядре из корня репозитория или папки lab5. Зависимости перечислены в корневом README. Таблицы результатов пересоздаются, графики находятся только внутри ноутбука.

Предобработка для модели обучается только на train. Демонстрационные Gender_Label, Education_Ord и City_Freq исключены из X. Цель Churn также исключена. Разбиение 75/25 стратифицировано; пропорциональная выборка реализована самостоятельно методом наибольших остатков.

Ключевые результаты: Churn=0.37125; случайная выборка из 100 строк даёт 0.32, стратифицированная — 0.37. ROC AUC модели на исходных данных ≈0.6611 против 0.5 у базовой модели. Стандартное отклонение оценки медианы Income при n=20/100/500: 10391/3887/1138. После удаления строк с искусственными пропусками остаются 415 обучающих и 132 тестовых строки; заполнение сохраняет все 600/200. Медиана не обязана давать лучшую ошибку восстановления при MNAR — результаты указаны без подгонки.

Условия вложения содержат противоречия: в данных нет операций и поддержки, поэтому эти метрики отмечены как недоступные; отдельно построено строго MECE-разбиение клиентов. Все три скейлера сохраняют форму распределения, меняя шкалу. Синтетический набор не используется для утверждений о реальных клиентах; один split и одна маска пропусков не дают надёжного рейтинга методов.
