# Лабораторная 4 Проверка гипотез

**Иноземцев Сергей Викторович · ЕТ-216**

В [lab4.ipynb](lab4.ipynb) объединены: A — описательная статистика, ИМТ, нормальность и сравнение роста, веса и ИМТ новорождённых; B — независимые t-тесты 15 психологических показателей; C — бонус Gauss с χ² Пирсона для Iris и сравнение сортов.

| Таблица | Назначение |
|---|---|
| Пренатальная диагностика.xlsx | Исходные данные новорождённых |
| Психологи.xlsx | Исходные психологические показатели |
| Iris.xlsx | Исходные измерения цветков |
| birth_welch.csv | Результаты сравнения новорождённых |
| psychology_welch.csv | Результаты сравнения психологических шкал |

Выполнять все части сверху вниз. Используется двусторонний t-тест Уэлча, исходные p-value, поправка Holm, 95% интервалы разности средних и Cohen d. Графики находятся только в ноутбуке; результаты тестов дополнительно сохраняются как таблицы CSV. Статистические выводы по учебным данным не являются медицинскими заключениями.
