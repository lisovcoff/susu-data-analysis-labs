**Тема:** Прикладные задачи на данных интернет-магазина.

Основной файл — [lab02_part2.ipynb](lab02_part2.ipynb). При запуске он создаёт `orders_raw.csv`, `orders_prepared.csv` и `figures/store_dashboard.png` в этой папке. Исходная выборка генерируется с seed=2024; результаты воспроизводимы.

Инструменты: Python, NumPy, Pandas, Matplotlib и Jupyter Notebook. В ноутбуке выполнены части 1–7 методички, приведены ответы на контрольные вопросы. Корневой README содержит сведения о работе и запуске.
