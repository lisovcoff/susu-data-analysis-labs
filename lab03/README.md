# Лабораторная работа 03

**ФИО:** Иноземцев Сергей Викторович  
**Группа:** ЕТ-216

**Тема:** Визуализация данных в Pandas, Matplotlib и Seaborn.

[Ноутбук](Inozemtsev_ET-216_lab03.ipynb) использует `datasets/StudentsPerformance.csv`. Построены столбчатая и круговая диаграммы, гистограммы, сетка из шести графиков Matplotlib, два pairplot и корреляционная heatmap. Дополнительно проверены структура, пропуски, границы оценок и экстремумы по IQR.

Файл данных находится в общей папке [datasets](../datasets); копировать его вручную в папку лабораторной не нужно. Графики сохраняются в `figures`. Результаты запуска включены в ноутбук.
