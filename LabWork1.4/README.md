# NumPy и статистический анализ

**ФИО:** Иноземцев Сергей Викторович  
**Группа:** ЕТ-216

[NumPy_statistics.ipynb](NumPy_statistics.ipynb) — выполнение приложения «Лаба 1 (ч.1.4).pdf», которое доступно в задании лабораторной 2. Вынесено отдельно от основных частей Pandas, как дополнительная работа по NumPy и статистике.

Выполнены свойства массивов, индексация, view/copy, булевы маски, выбросы, процентили, корреляция, Bootstrap и ответы на вопросы о гипотезах, p-value и бизнес-значимости.
