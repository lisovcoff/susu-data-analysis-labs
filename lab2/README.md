# Лабораторная 2 NumPy и Pandas

**Иноземцев Сергей Викторович · ЕТ-216**

В [lab2.ipynb](lab2.ipynb) последовательно выполнены три части: A — массивы NumPy, срезы и копии, маски, статистики, Bootstrap и гипотезы; B — конвейер Pandas для 15 заказов; C — подготовка и анализ 3000 синтетических заказов, фильтрация, группировки и девять визуализаций.

| Таблица | Назначение |
|---|---|
| online_store_orders.csv | 15 заказов из условия первой части Pandas |
| orders_raw.csv | Сгенерированные заказы до обработки 30 пропусков возраста |
| orders_prepared.csv | Подготовленные заказы с датами, выручкой, прибылью и возрастными группами |

Все части запускаются сверху вниз в одном ядре. CSV могут быть воспроизведены кодом; служебных папок и PNG ноутбук не создаёт. Выручка рассчитывается по условию для всех заказов, а фактическая — отдельно только по доставленным; cost означает себестоимость всего заказа. Объяснения и выводы находятся рядом с вычислениями.
