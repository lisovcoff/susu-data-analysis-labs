## Лабораторная работа 2 (часть 2)

**Тема:** Прикладные задачи на данных интернет-магазина.  
**Инструменты:** Python, NumPy, Pandas, Matplotlib, Jupyter Notebook.

Сформированы 3000 синтетических заказов (seed=2024), добавлены и обработаны 30 пропусков возраста. Выполнены фильтрация, группировка, девять визуализаций и мини-анализ. `revenue` рассчитана для всех заказов по условию; фактическая выручка дополнительно считается только по доставленным. `cost` означает себестоимость всего заказа.

## Запуск

Из корня репозитория:

```bash
python -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m pip install jupyterlab
.venv/bin/python -m jupyter lab
```

В Windows вместо `.venv/bin/python` используется `.venv/Scripts/python.exe`. Откройте ноутбук, выберите ядро созданной среды и выполните **Restart Kernel and Run All Cells**. Рабочая папка ядра должна совпадать с папкой ноутбука. Каждый ноутбук выполняется независимо. Результаты уже сохранены для просмотра на GitHub, графики также находятся в папках `figures`.
