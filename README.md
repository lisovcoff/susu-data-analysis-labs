## Лабораторная работа 2 часть 2

**Тема:** Прикладные задачи на данных интернет-магазина.

**Инструменты:** Python, NumPy, Pandas, Matplotlib, Jupyter Notebook.

Сформированы 3000 учебных заказов, проверены структура и пропуски, созданы признаки выручки, прибыли и возрастной группы. Выполнены фильтрация, группировки, визуализация и мини-анализ категорий, городов, скидок, VIP-заказов, отмен и возвратов. Данные генерируются с фиксированным seed=2024; они не являются реальными продажами.

## Запуск

Проверено на Python 3.12. Создайте отдельную среду и установите зависимости из корня репозитория:

```powershell
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
.venv/Scripts/python -m pip install jupyterlab
.venv/Scripts/python -m jupyter lab
```

Для Linux/macOS путь к Python среды — `.venv/bin/python`. В Jupyter выберите ядро этой среды. Откройте нужный ноутбук и выполните **Restart Kernel and Run All Cells**. Каждый ноутбук запускается независимо; запускать другие работы предварительно не требуется. Результаты ячеек также сохранены для просмотра на GitHub.

## Данные и методы

- Исходные задания и наборы данных взяты из [курса edu.susu.ru](https://edu.susu.ru/course/view.php?id=218588).
- В лабораторной 2 медиана и среднее пропускают NaN; влияние крупного заказа рассматривается отдельно. Для фактической выручки дополнительно анализируются только доставленные заказы.
- В лабораторной 3 `male` — фактическое значение поля пола, вместо опечатки `mail` в задании. Выбросы по IQR не удаляются автоматически.
- В лабораторной 4 выполняются конкретные прикреплённые задания о гипотезах и t-тестах. Применяется независимый t-тест Уэлча, приведены исходные p-value, поправка Holm, доверительные интервалы и размеры эффектов. Бонусная часть Iris включена в тот же ноутбук.
- Числа из учебного анализа не используются для медицинских или причинных заключений.

Краткие объяснения для защиты находятся в [DEFENSE.md](DEFENSE.md), протокол повторного запуска — в [VALIDATION.md](VALIDATION.md).
